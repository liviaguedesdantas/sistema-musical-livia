# 🎵 Sistema Musical

## 📌 Sobre o Projeto

O **Sistema Musical** é um projeto desenvolvido como atividade prática do curso Técnico em Desenvolvimento de Sistemas. O objetivo é criar uma interface para gerenciamento de artistas e músicas, permitindo organizar informações musicais por meio de telas de cadastro, listagem e login.

O projeto utiliza HTML e CSS para estruturar e estilizar as páginas, mantendo uma identidade visual padronizada em todo o sistema.

## 🚀 Funcionalidades

- **Tela de Login:** formulário para inserir usuário e senha.
- **Menu Principal:** acesso às funcionalidades do sistema.
- **Cadastro de Artistas:** formulário com nome, gênero musical, país e foto do artista.
- **Cadastro de Músicas:** formulário com artista, título, álbum, gênero, link do YouTube, capa e letra da música.
- **Biblioteca Musical:** listagem de músicas cadastradas em tabelas.
- **Filtros:** pesquisa de músicas por título, álbum, artista e gênero.
- **Layout Responsivo:** adaptação das páginas para dispositivos móveis.

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Live Server
